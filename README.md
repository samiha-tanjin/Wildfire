# The Surface

A web application built for the **NASA Space Apps Challenge 2026**. The web application explains what a wildfire is, how it is born, its global impact, has a calendar presenting previous wildfire history along with future fire predictions (planned), has built-in features that alert registered users about wildfire breakouts and lets the user plan out their day based on their location's weather information.

**Challenge:** Harmonization of MODIS and VIIRS Hotspots 

## Documentation Video 
[Watch the 240 seconds demo video](https://youtu.be/ac1AEY_QsIo)

## Features
- Primary information section about wildfires
- A report analysis on wildfire's impact on economy
- Live hotspots tracking system
- A wildfire calendar
- Alerting system to notify users about wildfire breakouts and predictions
- Chatbot system for users to plan out their day based on their location

## Run the Project Locally 
### Requirements list
- [Node.js](https://nodejs.org) (recent LTS version)
- [Git](https://git-scm.com)
- Code editor such as [VS Code](https://code.visualstudio.com)
### Steps 
- Clone the repository
  ```bash
  git clone https://github.com/samiha-tanjin/The-Surface-web-application.git
  cd The-Surface-web-application
  ```
- Install the dependencies
  ```bash
  npm install
  ```
- Start the development server
  ```bash
  npm run dev
  ```
- Open the local host link in your browser (usually http://localhost:5173/)
### Commands 
- `npm run build`
- `npm run preview`

In order to close the server use keyboard shortcut `Ctrl + C`
